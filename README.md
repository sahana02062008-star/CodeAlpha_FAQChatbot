# CodeAlpha_FAQChatbot
AI FAQ Chatbot

About

This project is an AI-powered FAQ chatbot built using Python, NLTK, and TF-IDF similarity matching. It answers user questions using a predefined FAQ dataset.

Features

- Answers frequently asked questions about AI.
- Preprocesses text using NLTK.
- Uses TF-IDF and cosine similarity to find relevant answers.
- Supports interactive questions in the terminal.

Technologies Used

- Python
- NLTK
- Scikit-learn

How to Run

1. Install the required libraries:
   "pip install nltk scikit-learn"
2. Run the program:
   "python faq_chatbot.py"
3. Type a question and read the chatbot's answer.
4. Type "exit" to stop the chatbot.
